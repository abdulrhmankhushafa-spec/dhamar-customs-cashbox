# نظام صندوق مكتب العمال - ساحة الأربعين - جمارك ذمار (Flutter Offline-First)

تطبيق أندرويد متكامل مبني بإطار **Flutter** ويعمل **بدون إنترنت بالكامل (Offline)** عبر قاعدة بيانات محلية `SQLite`.

## المميزات الأساسية
1. **نافذة سند الصرف (مطابقة للسند الورقي لمكتب العمال - جمارك ذمار):**
   - تسجيل رقم السند الورقي (مثل `0086883`)، التاريخ، اسم التاجر، المبلغ رقماً وكتابةً (تفقيط تلقائي بالعربي)، رقم اللوحة، رقم القعادة، رقم البيان، نوع البضاعة، نوع العمل، وعدد العمال.
   - **تصوير السند الورقي** بالكاميرا أو اختياره من الاستوديو وحفظه محلياً داخل الجهاز.
   - **قراءة البيانات تلقائياً من صورة السند الورقي (OCR / AI Vision)**.
   - إظهار **الرصيد السابق + مبلغ السند الحالي = إجمالي الحساب المستحق على التاجر** فوراً.
2. **إرسال مضمون 100% إلى واتساب + ربط جهات الاتصال:**
   - عند الضغط على **(حفظ وإرسال واتساب)** تظهر نافذة تتيح الإرسال إلى **الرقم الأساسي للتاجر** أو **اختيار أي رقم آخر من جهات اتصال الهاتف مباشرة** قبل الإرسال.
   - يدعم إرسال **صورة السند الورقي مرفقة مع نص تفاصيل السند وإجمالي حساب التاجر**، أو فتح محادثة الرقم مباشرة في واتساب الرسمي أو واتساب الأعمال.
3. **نافذة سند القبض:**
   - تسجيل الدفعات المستلمة من التجار، خصمها تلقائياً من إجمالي حسابهم، وإرسال إشعار قبض عبر واتساب.
4. **كشوفات الحسابات وإدارة التجار:**
   - كشف حساب تفصيلي لكل تاجر أو لجميع التجار مع معاينة صور السندات الورقية وإرسال كشف الحساب عبر واتساب.
